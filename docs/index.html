The forecast, one press away.Прогноз — одним нажатием.

Press down on the remote for the hour-by-hour forecast, sunrise and sunset, and the next three days. The weather icons are redrawn for a big screen and read clearly from the sofa. The drawer is drawn by hand on a single canvas, built for 60 frames per second on the TV's own modest chip.Нажмите вниз на пульте — появятся прогноз по часам, восход и закат и погода на три дня. Иконки погоды нарисованы заново для большого экрана и хорошо читаются с дивана. Панель рисуется вручную на одном холсте и рассчитана на 60 кадров в секунду на скромном процессоре самого телевизора.

Your own server, one button.Свой сервер, одна кнопка.

Paste a share link from any panel or provider: vless://, vmess://, trojan:// or ss://. Optional: leave it empty and there's no VPN at all.Вставьте ссылку из любой панели или от провайдера: vless://, vmess://, trojan:// или ss://. По желанию: без ссылки VPN просто нет.

Ten minutes, one computer.Десять минут и один компьютер.

You build the app with your own settings (your city, your server) and install it over Wi-Fi. You'll need a JDK 17, the Android SDK command-line tools and adb.Приложение собирается с вашими настройками (город, сервер) и ставится по Wi-Fi. Понадобятся JDK 17, Android SDK command-line tools и adb.

  1. Turn on USB debugging on the TVВключите отладку по USB на телевизоре

    Settings → Device Preferences → About → press Build 7 times. Then Developer options → USB debugging. Note the TV's IP address.Настройки → Настройки устройства → Об устройстве → нажмите Сборка 7 раз. Затем «Для разработчиков» → «Отладка по USB». Запишите IP-адрес телевизора.

  2. Get the codeСкачайте код

    git clone https://github.com/Melidovskiy/your-tv && cd your-tv
tools/fetch_libs.sh
./build.sh   # creates config.properties

  3. Fill in your settings and buildЗаполните настройки и соберите

    Your city, an optional TMDB key for the picks, an optional proxy link. Then:Ваш город, ключ TMDB для подборок и ссылку на прокси — по желанию. Затем:

    ./test.sh && ./build.sh

  4. Install over Wi-FiУстановите по Wi-Fi

    adb connect <TV IP>:5555
adb install -r FreeMyTV.apk

    The TV asks Allow USB debugging?: tick Always allow.Телевизор спросит «Разрешить отладку по USB?» — отметьте «Всегда разрешать».

  5. Switch on the TVПереключите на телевизоре

    Open Home Screen → Home Screen → New, and allow debugging once more.Откройте «Главный экран» → «Главный экран» → «Новый» и ещё раз разрешите отладку.

Always a way backВсегда можно вернуть

Original brings back the stock home screen, screensaver and apps. If the new screen ever crashes three times in five minutes, the TV switches back by itself.«Заводской» возвращает родной экран, заставку и приложения. Если новый экран упадёт три раза за пять минут, телевизор вернётся к заводскому сам.
